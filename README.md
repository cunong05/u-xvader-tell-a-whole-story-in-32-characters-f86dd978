**"Tell a Whole Story in 32 Characters"** — one Wi-Fi network name of at most
32 characters, the funniest name that hints at a whole story.

## The entry

```
Loved. Lost. Learned. Lived on.
```

31 characters. Four beats, one life: a love, a loss, a lesson, and the
quiet punchline — he lived on. The whole arc of a romance in the few words
a stranger sees in a phone's network list.

## Run

```sh
python3 main.py
```

Prints the entry and writes it to `/output/entry.txt`.
